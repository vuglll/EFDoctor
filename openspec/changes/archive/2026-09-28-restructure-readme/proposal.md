# Proposal

## Why

The README is the page most visitors read, and it currently reads like internal project notes:
- It opens with "Project status: validation MVP", then an implementation history of OpenSpec change names.
- Its roughly 500 lines mix user documentation, 18 per-rule boundary summaries, suppression details, and contributor material.
- It shows no example of what the tool finds.

A visitor can't tell in a few seconds what EFDoctor does or why they should try it.

## What Changes

- **`README.md` becomes a landing page:**
  - a one-line pitch and badges (CI, NuGet version, license);
  - an animated terminal demo of real output;
  - a quick start;
  - real findings from Microsoft's eShop, with the code and the fix;
  - the validation results in brief;
  - the rule table and links to the detailed documents.

  The "MVP" wording goes.
- **The detail moves to focused documents:**
  - `docs/usage.md`: commands, options, exit codes, JSON output, installation variants, prerequisites, and the trust boundary;
  - `docs/suppression.md`: suppressing intentional findings, and the per-rule notes;
  - `docs/rules/README.md`: the query-locals rules and a boundary summary for each rule;
  - `docs/development.md`: build and test, repository layout, the verification map, and the implementation history.
- **Sections the roadmap already covers are dropped:** "Planned technical direction", "Validation standard", "Out of scope for the first milestone", and "Product background".
- **The demo:** `docs/assets/demo.svg` is an animated SVG generated by `docs/assets/render-demo.py` from `docs/assets/demo.txt`, a transcript of `efdoctor` 0.2.0 run on eShop at commit `b4a4087`. It is trimmed to two findings, with paths shown relative to the checkout.
- **Links:** the rule pages that link `README.md#query-locals` now point to `docs/rules/README.md#query-locals`.
- **Checks:** `RepositoryConsistencyTests` reads the verification map from `docs/development.md`, and `CONTRIBUTING.md` names the new locations of the manually maintained sections.

## Capabilities

### Modified Capabilities

- `repository-consistency`: the verification map's analyzer-test list lives in `docs/development.md` instead of the README.

## Impact

- **Documentation:** the README, four new documents under `docs/`, eight rule pages (links), and `CONTRIBUTING.md`.
- **Tests:** `RepositoryConsistencyTests` (one path).
- **Behavior:** none.
