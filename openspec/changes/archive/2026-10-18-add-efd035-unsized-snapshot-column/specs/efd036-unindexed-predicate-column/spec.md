## ADDED Requirements

### Requirement: Read generated model snapshots
EFD036 SHALL read index and key coverage from model snapshots that are generated code, marked `// <auto-generated />`, because EF Core generates every snapshot that way. It SHALL NOT collect predicates from generated code, and SHALL NOT report in it.

#### Scenario: Generated snapshot and generated queries
- **WHEN** the model snapshot is in a file marked `// <auto-generated />`, and a query in an ordinary file filters on an unindexed column
- **THEN** EFD036 reports the query, and does not report the same query when its own file is marked generated
